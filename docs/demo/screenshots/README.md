# Screenshots

The images in this folder are from the previous book of business. They were not regenerated in the nonprofit reskin. Recreate them against the live portal, or from the mock console with `node scripts/screenshot.mjs`, after `pnpm demo:mock`.

| File | Page |
| --- | --- |
| `01-login.png` | Sign-in. The demo password is on the page. |
| `02-queue.png` | Queue grouped by client, with band, score, kind, and age. |
| `03-proposal.png` | One proposal: procedure version, policy rule, action hash, citations, approve / reject / edit. |
| `04-runs.png` | Two live sweeps. The later one committed nothing new. |
| `05-run.png` | One run's proposals. |
| `06-audit.png` | Latest audit rows. The log is append-only. |
| `07-metrics.png` | Rates and the 25-minute assumption. |
| `08-queue-mobile.png` | The same queue at a phone width. |

Timestamps on the pages are UTC.

HubSpot record screenshots are not in this folder. The list to capture on a test portal is in `docs/demo/real-hubspot-checklist.md`.
